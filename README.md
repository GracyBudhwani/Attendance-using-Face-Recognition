# Attendance-using-Face-Recognition
A beginner friendly python project that can recognise your face using python and mark the real time attendance in SQL.

Pre-requisites:
    1) Python ver 3.14.7
    2) SQL
    3) OpenCV module python
    4) mysql.connector module python
    5) face_recognition module python
    6) os module python
    7) datetime module python
